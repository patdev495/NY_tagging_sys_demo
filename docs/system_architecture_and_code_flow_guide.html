3 Luồng Code 1: Trạm Đóng Gói UI (Item Scan Mode)

Chế độ áp dụng cho khách hàng Universal Instruments (UI). Công nhân quét từng sê-ri sản phẩm (Item SN) cho tới khi đủ số lượng packed_qty (hoặc đóng thiếu nếu có cờ allow_partial).

Sơ đồ luồng xử lý từ lúc nhập Job Order đến khi in tem:

1. Công nhân nhập Job Order (vd: 24080123)
   │
   ├──> Backend truy vấn ERP [192.168.206.18].ShopFloorDW.DBO.F4801
   │    Lấy ra: Mã liệu (walitm), Khách hàng (wadl01), Số lượng (wauorg)
   │
   ├──> Khớp với Product trong DB -> Tính tổng số thùng: N = ceil(Quantity / packed_qty)
   │
   └──> Cấp phát trước N Slot thùng (job_order_carton_slots) với Carton SN tăng dần:
        Format: CN + YYMM + [Product Letter] + [5-digit Counter: 00001..99999]
        (Reset số thứ tự về 00001 vào ngày đầu tiên mỗi tháng)
   │
2. Trạm đóng gói nhận danh sách Slot -> Chọn Slot 1 (PENDING)
   │
   ├──> VÒNG LẶP QUÉT SÊ-RI CON (Item SN):
   │    - Kiểm tra độ dài & Regex Pattern
   │    - Kiểm tra trùng lặp trong bộ đệm quét hiện tại (scannedItems)
   │    - Gọi API kiểm tra xung đột DB: ui_item_sn_claims
   │      -> Nếu mã đã thuộc thùng khác: Báo động âm thanh, mở Modal tra cứu lịch sử thùng cũ
   │    - Đạt đủ số lượng packed_qty (ví dụ: 15/15 PCS)
   │
3. KÍCH HOẠT HOÀN TẤT THÙNG (Finalize Carton):
   │
   ├──> Backend: Tạo bản ghi Carton với status = 'FAILED' (Mẫu FAILED-First)
   │    - Lưu quan hệ CartonItem và xác lập quyền sở hữu trong ui_item_sn_claims
   │    - Render file BarTender XMLScript (BTXML) nạp các trường:
   │      ItemName, QTY, CartonSN, UPC, QR_Content (chứa 15 sê-ri con cách nhau bởi \n)
   │    - Lưu chuỗi BTXML vào cột carton.btxml (để in lại bất kỳ lúc nào)
   │
   ├──> Client gửi BTXML tới Print Agent cục bộ (http://127.0.0.1:8001/print)
   │    - Print Agent gọi BarTender COM Engine mở template carton.btw
   │    - Nạp NamedSubStrings -> Kích hoạt Format.PrintOut()
   │
   └──> Máy in nhả tem thành công -> Gửi phản hồi 200 OK
        - Backend cập nhật status = 'SUCCESS' (hoặc 'PRINTED')
        - Cập nhật slot status = 'SCANNED'
        - Trạm đóng gói rơi vào trạng thái KHÓA CHỜ (Awaiting Next):
          Công nhân PHẢI bấm nút "Thùng tiếp theo" hoặc nhấn phím Spacebar mới được quét thùng kế!

Đoạn Code Cốt Lõi: Mẫu FAILED-First & Đặt Claim Chống Trùng (service.py)

# backend_v2/src/features/carton/service.py
def create_carton(carton_in: schemas.CartonCreate, db: Session):
    # 1. Khóa hàng Product bằng with_for_update() để ngăn chặn Race Condition
    product = db.query(models.Product).filter(
        models.Product.id == carton_in.product_id
    ).with_for_update().first()

    # 2. Kiểm tra xung đột Item SN cấp độ DB thông qua bảng ui_item_sn_claims
    if product.customer and product.customer.code == "UI":
        reject_ui_item_sn_conflicts(db, carton_in.items)

    # 3. Lấy slot thùng đang chờ (PENDING)
    slot = slot_lifecycle.get_pending_slot_for_carton_creation(
        db, slot_id=carton_in.slot_id, job_order=carton_in.job_order, product_id=carton_in.product_id
    )

    # 4. Khởi tạo Carton với trạng thái ban đầu là 'FAILED'
    # Đảm bảo nếu BarTender bị kẹt giấy/lỗi nguồn, sê-ri vẫn được bảo toàn và cho phép Retry
    new_carton = models.Carton(
        product_id=product.id,
        carton_sn=slot.carton_sn,
        packed_by=carton_in.printer_name or "System",
        job_order=carton_in.job_order,
        status="FAILED",
        carton_origin=carton_in.carton_origin,
        station_id=carton_in.station_id
    )
    db.add(new_carton)
    db.flush()

    # 5. Chiếm quyền sở hữu Item SNs
    if product.customer and product.customer.code == "UI":
        replace_ui_item_sn_claims(db, new_carton.id, carton_in.items)

    # 6. Sinh chuỗi BarTender XMLScript (BTXML)
    btxml_content = generate_btxml(new_carton, product, carton_in.items, path_to_use, carton_in.printer_name)
    new_carton.btxml = btxml_content
    db.commit()
    db.refresh(new_carton)
    return new_carton, btxml_content

4 Luồng Code 2: Trạm Cân Đóng Gói Erro (Weight Scale Mode)

Chế độ áp dụng cho dự án cáp Amazon eero sản xuất tại nhà máy Nien Yi. Không cần quét sê-ri con mà dựa vào trọng lượng thực tế của thùng hàng đặt trên bàn cân điện tử OKS để tự động kích hoạt in tem.

Nguyên Lý Nhận Diện Công Lệnh Erro Factory P/N Mapping

Khi nhập mã công lệnh (Job Order) tại trạm cân Erro:

  • Hệ thống tra cứu bảng ShopFloorDW.DBO.F4801 lấy trường walitm (Mã liệu nội bộ xưởng - Factory P/N).
  • Khớp chính xác với bảng product_internal_factory_part_numbers để xác định chính xác mẫu tem (erro_01 đến erro_05).
  • Tuyệt đối không suy luận mẫu tem từ SKU hay mô tả sản phẩm để tránh sai sót bản vẽ kỹ thuật.
Kiểm Soát Dung Sai Cân (Tolerance Engine) Zero Defect

Điều kiện tiên quyết để hệ thống chấp thuận lệnh in tem:

  • Đầu cân đang kết nối và ở trạng thái Ổn Định (Stable / ST).
  • Trọng lượng thực tế: min_weight <= Weight <= max_weight.
  • Nếu thiếu dù chỉ 1 sợi cáp (Underweight) hoặc thừa/bỏ quên đồ vật (Overweight): Khóa cứng nút in, đổi màu giao diện sang Đỏ/Vàng và phát âm thanh cảnh báo lỗi!

def weigh_pack_carton(weigh_in: schemas.CartonWeighPackCreate, db: Session):
    product = db.query(models.Product).filter(models.Product.id == weigh_in.product_id).with_for_update().first()
    
    # ADR 0005/0006: Khách hàng Erro TUYỆT ĐỐI CẤM người vận hành sửa sê-ri thùng bằng tay
    if product.customer.code == "ERRO" and (weigh_in.custom_sn is not None or weigh_in.custom_yymm is not None):
        raise HTTPException(status_code=400, detail="Khách hàng ERRO không cho phép chỉnh sửa sê-ri thủ công!")

    # Kiểm tra dung sai trọng lượng nghiêm ngặt
    if product.min_weight and weigh_in.weight < product.min_weight:
        raise HTTPException(status_code=400, detail=f"Trọng lượng {weigh_in.weight}kg dưới mức cho phép {product.min_weight}kg")
    if product.max_weight and weigh_in.weight > product.max_weight:
        raise HTTPException(status_code=400, detail=f"Trọng lượng {weigh_in.weight}kg vượt mức cho phép {product.max_weight}kg")

    # Snapshot LOT Number = YYYYMMDD theo Local Server Time
    allocated_at = datetime.now()

    # Điều hướng tới Allocator chuyên biệt của từng mẫu tem
    if product.template_type == "erro_01":
        plan = plan_next_erro_01_carton_sn(db, product, custom_yymm=allocated_at.strftime("%y%m"), lock=True)
    elif product.template_type == "erro_02":
        plan = plan_next_sscc_carton_sn(db, product, lock=True)  # GS1-128 SSCC-18
    elif product.template_type == "erro_03":
        plan = plan_next_erro_03_carton_sn(db, product, custom_yymmdd=allocated_at.strftime("%y%m%d"), lock=True)
    elif product.template_type == "erro_04":
        plan = plan_next_erro_04_carton_sn(db, product, printed_at=allocated_at, lock=True)  # Base32 Year Reset
    elif product.template_type == "erro_05":
        plan = plan_next_erro_05_carton_sn(db, product, printed_at=allocated_at, lock=True)  # Pegatron Monthly Reset 50001-99999

5 Chi Tiết Thuật Toán Sinh Carton SN Của 5 Mẫu Tem Erro

Mỗi dòng tem được thiết kế để thỏa mãn tiêu chuẩn kiểm toán quốc tế khắt khe từ Amazon, Luxshare và Pegatron.

erro_01 · Bản vẽ PD014736 (Tem Đứng eero Retail 3x5") Reset 01/01 hàng năm

Cấu trúc: {pkg_prefix}{YYMM}{Sequence:06d} (ví dụ: VHK00102372609000125)

  • pkg_prefix: Mã tiền tố sản phẩm cấu hình riêng theo Product (vd: VHK0010237).
  • YYMM: 2 số cuối năm + 2 số tháng sản xuất.
  • Bộ đếm sê-ri: 6 chữ số (000001 - 999999). Bộ đếm tách biệt độc lập theo từng Product.
  • Mã vạch 2D QR Code: Chứa 7 trường ngăn cách bởi dấu phẩy: P{CPN},Q{QTY},M{MfrPN},D{DateCode},L{LotNo},K{PONo},S{CartonSN}. Bắt buộc phải có PO Number và Lot Number!
erro_02 · Bản vẽ PD027504 (Tem Ngang CM Pallet SSCC-18 152x95mm) KHÔNG BAO GIỜ RESET

Cấu trúc: (00) 0 37033907 {Sequence:07d} {CheckDigit}

  • Mã định danh GS1: Tiêu chuẩn GS1-128 Serial Shipping Container Code (18 số).
  • 37033907: Mã định danh doanh nghiệp GS1 chính thức của Nien Yi.
  • Bộ đếm: 7 chữ số (0000001 - 9999999) tăng liên tục toàn hệ thống giữa các mã cáp Tem 2, không bao giờ reset.
  • Check Digit (Modulo 10): Tính theo công thức trọng số chuẩn GS1 (3-1-3-1...).
# Thuật toán tính chữ số kiểm tra Modulo 10 GS1
def calculate_gs1_check_digit(number_str: str) -> int:
    clean_str = "".join(c for c in str(number_str) if c.isdigit())
    total = 0
    weights = [3, 1]
    for i, char in enumerate(reversed(clean_str)):
        weight = weights[i % 2]
        total += int(char) * weight
    remainder = total % 10
    return 0 if remainder == 0 else (10 - remainder)
erro_03 · Bản vẽ PD024364 (Tem Xuất Xưởng Luxshare 立讯 100x80mm) Reset 01/01 hàng năm

Cấu trúc Carton SN: 1012665{YYMMDD}{Sequence:04d} (ví dụ: 10126652609050012)

  • 1012665: Mã nhà cung ứng Nien Yi Việt Nam tại hệ thống Luxshare NME.
  • YYMMDD: 6 chữ số ngày sản xuất.
  • Bộ đếm: 4 chữ số (0001 - 9999), reset về 0001 vào ngày 01/01 hàng năm, phân vùng theo Product và Supplier Code.
  • QR Code Luxshare: {CartonSN}${SupplierCode}${SupplierName}${LuxsharePartNo}${APNRev}${LotNo}${Date}${QTY}$$$$$$
erro_04 · Bản vẽ PD027032 (Tem eero Mỹ Basic Box 102x76mm) Chuỗi Base-32, Reset 01/01

Cấu trúc: {Prefix}{YearCode}{MonthCode}{DayCode}{Sequence:4-char Base32} (8 ký tự, vd: H69500A2)

  • Prefix: Cố định theo loại cáp: H (cho CAT6A) hoặc K (cho CAT5E).
  • Bảng ký tự Base-32: 0123456789ABCDEFGHJKMNPQRSTVWXYZ (32 ký tự, loại bỏ hoàn toàn các ký tự dễ nhầm lẫn: I, L, O, U).
  • Mã hóa ngày: Năm 2026 = 6, Tháng 9 = 9, Ngày 5 = 5 -> Date code = 695.
  • Bộ đếm dùng chung: Toàn bộ sản phẩm erro_04 dùng chung 1 bộ đếm sê-ri 4 ký tự base-32 từ 0001 đến ZZZZ (tương đương 1 đến 1,048,575 thùng/năm).
erro_05 · Bản vẽ PD016906 (Tem Thùng Ngoài Pegatron NN9 102x77mm) Dải 50001 - 99999, Reset hàng tháng

Cấu trúc: MC220TW12{YY}{WW}{Sequence:50001..99999} (18 ký tự, vd: MC220TW12263650028)

  • MC220TW1: Mã nhà cung ứng Pegatron cấp cho xưởng Nien Yi.
  • 2: Chữ số cố định chỉ định xưởng Việt Nam.
  • YYWW: Năm (2 số) + Tuần sản xuất theo chuẩn ISO 8601 (2 số).
  • Quy tắc Reset: Tự động reset về 50001 vào đúng 00:00 ngày 1 hàng tháng theo giờ máy chủ. Không reset theo tuần! Dùng chung cho toàn bộ 38 mã hàng Pegatron.

6 Động Cơ In Ấn: BarTender COM Automation & BTXML Script

Hệ thống không render tem thành ảnh tĩnh mà tương tác trực tiếp với động cơ Seagull BarTender cài trên Windows thông qua chuẩn kết nối COM Automation (Component Object Model).

Tại sao dùng BarTender COM? Tối Ưu Phần Cứng
  • Gửi lệnh in dạng vector trực tiếp tới Driver máy in công nghiệp (Zebra ZPL, TSC TSPL) cho tốc độ in tức thì (< 200ms).
  • Chất lượng in mã vạch 1D và QR code sắc nét ở độ phân giải 203 DPI / 300 DPI, vượt qua mọi bài kiểm tra máy đọc kiểm định hàng xuất khẩu.
  • Tách rời thiết kế tem (.btw) khỏi code: Kỹ sư khuôn mẫu có thể chỉnh sửa font, logo trên BarTender Designer mà không cần sửa code Python.
Cơ Chế Tự Phục Hồi (Self-Healing Engine) Zero Downtime
  • Thread Safety: Đảm bảo pythoncom.CoInitialize() trên từng luồng thực thi để tránh lỗi COM Access Violation.
  • Singleton Lock: Toàn bộ tiến trình in được đồng bộ hóa qua threading.Lock().
  • Auto-Kill Orphaned Processes: Khi BarTender bị treo hoặc rơi vào trạng thái Modal Dialog bí mật, lớp BarTenderCOMApp tự động chạy taskkill /F /IM bartend.exe và tái khởi động lại kết nối COM sạch sẽ.

7 Tầng Tích Hợp Cân Điện Tử: Serial RS-232 & Global Hotkeys

Tầng giao tiếp phần cứng cân nằm trong module print_agent_v2/scale/. Quản lý việc kết nối đầu cân OKS, lọc nhiễu gói tin ASCII và kích hoạt cân bằng phím tắt toàn cục.

Trình Bóc Tách Gói Tin Cân (parser.py) ASCII Continuous Stream

Đầu cân phát luồng liên tục 10-20 gói/giây qua cổng RS-232. Gói tin có dạng: ST,GS,+0005.42kg\r\n hoặc US,NT,+0000.00kg.

  • Loại bỏ ký tự điều khiển STX (\x02) và khoảng trắng thừa.
  • Lọc bỏ các dòng thông tin phi-trọng lượng: dòng ngày giờ (DATE, TIME, AM/PM), dòng gạch phân cách (===).
  • Phân tích cờ trạng thái: ST (Ổn định - Stable), US (Không ổn định - Unstable), GS/NT (Gross/Net weight).
  • Trích xuất số cân thực tế bằng Regex: (?P<weight>[+-]?\s*\d+(?:[.,]\d+)?).
Lắng Nghe Phím Tắt Toàn Cục (hotkey.py) Windows Hook

Khi công nhân đang thao tác trên bàn cân hoặc dùng bàn đạp chân (foot pedal):

  • Đăng ký Hook bàn phím toàn cục mức hệ thống Windows (Low-level Keyboard Hook qua ctypes hoặc keyboard module).
  • Hỗ trợ phím F9 hoặc Spacebar. Khi nhấn, Print Agent ngay lập tức bắt sự kiện và thông báo tới giao diện Web qua WebSocket hoặc Polling để thực hiện cân và in tem mà công nhân không cần rời tay click chuột.

Bước 2: Xây dựng Module BarTender COM Singleton

Viết lớp kết nối BarTender bọc trong threading.Lock() và hỗ trợ chế độ MOCK khi lập trình trên macOS / Linux: 

import threading, os
try:
    import pythoncom, win32com.client
    HAS_WINDOWS = True
except ImportError:
    HAS_WINDOWS = False

class BarTenderEngine:
    _instance = None
    _lock = threading.Lock()

    def print_label(self, btw_file: str, printer: str, substrings: dict):
        with self._lock:
            if not HAS_WINDOWS:
                print(f"[MOCK PRINT] File: {btw_file}, Data: {substrings}")
                return True
            pythoncom.CoInitialize()
            app = win32com.client.Dispatch("BarTender.Application")
            format_doc = app.Formats.Open(btw_file, False, "")
            format_doc.Printer = printer
            for key, val in substrings.items():
                try:
                    format_doc.NamedSubStrings(key).Value = str(val)
                except Exception:
                    pass
            format_doc.PrintOut(False, False)
            format_doc.Close(1)  # 1 = btDoNotSaveChanges
            return True

Bước 3: Xây dựng Bộ Đệm Đọc Cân RS-232 Liên Tục

import serial, threading, re

class ScaleReader(threading.Thread):
    def __init__(self, port="COM3", baudrate=9600):
        super().__init__(daemon=True)
        self.ser = serial.Serial(port, baudrate, timeout=1)
        self.current_weight = 0.0
        self.is_stable = False

    def run(self):
        pattern = re.compile(r"(?P<flag>ST|US).*?(?P<w>[+-]?\s*\d+(?:\.\d+)?)\s*kg", re.IGNORECASE)
        while True:
            line = self.ser.readline().decode("ascii", errors="ignore")
            m = pattern.search(line)
            if m:
                self.is_stable = (m.group("flag").upper() == "ST")
                self.current_weight = float(m.group("w").replace(" ", ""))
